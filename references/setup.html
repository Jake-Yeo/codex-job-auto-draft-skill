Set up Job Applications

Connect ChatGPT to Chrome, load AutoApply for PDF uploads, and set up your private profile.

Skill setup

  1. Install the portable skill

    With Python 3.10 or later installed, place this folder at ~/.codex/skills/job-applications/. Use a clean destination if you already have a customized copy.

  2. Connect ChatGPT to Chrome

    In ChatGPT desktop, go to Settings → Computer Use → Google Chrome. If you see Install, follow the prompt to add the ChatGPT extension. When Chrome shows Manage, it’s connected. Use this same Chrome profile for the upload extension and your application tabs.

  3. Load AutoApply PDF Uploads

    Run the build command in Terminal. It creates this computer’s extension folder and prints its path.

    python3 ~/.codex/skills/job-applications/scripts/attach_documents.py build

    In Chrome, open chrome://extensions, turn on Developer mode, and choose Load unpacked. Select the path printed by the build. The default folder is:

    ~/.local/share/job-applications/attachment-extension

    Look for AutoApply PDF Uploads. If it’s already installed, use its reload button after rebuilding.

  4. Set up your profile

    In a local Codex chat, send the setup prompt. The skill will ask for the details, documents, and links still missing from your profile.

    $job-applications setup

    Your answers and generated profile page stay in the private data folder on this computer.

  5. Start a draft batch

    Group your application tabs under jobs. In a local Codex chat, select @Chrome and ask the skill to draft them.

    Use $job-applications to draft the tabs in my Chrome jobs group.

    The skill uses your saved profile and résumé. Review the drafts and attachments in Chrome before you submit.
